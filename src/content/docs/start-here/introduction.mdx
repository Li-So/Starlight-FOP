Welcome to the Foundations of Programming website! There are a few things you should know before you get started with the guide, primarily associated with the guide sections.


## What you'll learn

At the beginning of every section, you will notice a callout like this listing what you will learn (or do) in a given section.

:::tip[What you'll learn]{icon="document"}
- Information about exercises
- Admonitions
- Website purpose, maintainer & contribution
:::

## Exercises

At various points of the guides, there may be code like this underneath a given task:

```js
function someTask(){
    // Write your code here!
}
```

Please note the double slash `//` indicates a comment; I expect _you_ to implement the function as an exercise. Use the earlier guided exercises and search the internet if you get stuck. Arguably, getting stuck is the part you will learn the most from, and _if_ you choose to use AI, make sure you understand each step.

## Notes and admonitions

As you read through chapters, you may notice notes or admonitions such as these:

:::tip
A line starting with `//` is commented and will not be part of the code. You can use it as your own note for how a function works.
:::

:::caution
Don't run all of your assignments through AI without understanding the code! Understanding code is the most pivotal part of this course and doing so would be self-sabotage. In addition, it is generally not difficult to detect.
:::

Keep an eye out for them during the chapters.
